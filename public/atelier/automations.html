      n8n, Gmail, OpenAI · 9 steps

      How do I get AI to draft customer service replies in Gmail?

      CS Live Inbox is an n8n workflow Omhar Regidor built for Comfit. A low-cost OpenAI model reads every new support email first. Only emails that need an answer go on to a stronger model, which looks up the order in the store and writes a reply. The reply is saved as a Gmail draft, so a person reviews it and presses send. Emails that need no reply get a cs-skipped label.

      1. Gmail Trigger starts a run when a new email arrives
      2. Filter keeps only real customer emails
      3. A low-cost OpenAI model checks if the email needs a reply
      4. An IF step sends it to the reply path or the skip path
      5. An HTTP request looks up the order in the store
      6. A stronger OpenAI model writes the reply
      7. The reply is saved as a Gmail draft for review
      8. The run is logged to a database
      9. Emails that need no reply get the cs-skipped label

      n8n, Shopify, OpenAI, Slack · 6 steps

      How do I get a daily Shopify sales summary in Slack?

      Daily Sales Pulse is an n8n workflow Omhar Regidor built for Comfit. Every day a schedule pulls the store’s orders from Shopify. JavaScript code adds up the totals and trends, so the numbers are exact, and an OpenAI model only writes the short summary. The summary is posted to the team’s Slack channel and every run is logged.

      1. A schedule starts the run once a day
      2. Shopify returns the store’s recent orders
      3. JavaScript code works out the totals and trends
      4. An OpenAI model writes a short summary of the numbers
      5. Slack posts the summary to the team channel
      6. The run is logged to a database

      n8n, Slack, OpenAI · AI agent

      How do I build a Slack bot that answers staff questions about procedures?

      SOP Assistant is an n8n AI agent Omhar Regidor built for Comfit. Staff ask a question in Slack or in a chat window, and one AI agent answers it from the company’s written procedures using an OpenAI chat model. Slack gets an instant receipt so it does not time out, and the chat window remembers recent messages so follow-up questions make sense.

      1. A webhook receives the question from Slack, or the chat window starts a run
      2. Slack gets an instant receipt so it does not time out
      3. An AI agent reads the question and answers from the written procedures
      4. An OpenAI chat model writes the answer, with short memory in the chat window
      5. The answer is posted back where the question was asked
