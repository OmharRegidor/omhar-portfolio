Can AI answer my customer emails?

Yes, with a person still in control. In Omhar Regidor’s CS Live Inbox workflow, a low-cost AI model first checks whether each new email needs a reply. Emails that do get a reply written by a stronger model and saved as a Gmail draft, so someone on the team reviews it before it is sent. See how CS Live Inbox works.

Can you build a booking website with an AI assistant?

Yes. BiNuKBoK View Point Resort is a full-stack booking site Omhar Regidor built with online reservations, an availability calendar, QR-code check-in, an admin dashboard and an AI assistant that answers live availability and guest-arrival questions from the database. Visit the live site.

Can I add an AI assistant to Slack or my website?

Yes. Omhar Regidor’s SOP Assistant is an AI agent built in n8n that answers staff questions about company procedures. The same assistant works inside Slack and as a chat window, and the chat version remembers recent messages so follow-up questions make sense. See the SOP Assistant.

Can you build a mobile app as well as a website?

Yes. Noxa Loyalty, a customer loyalty platform Omhar Regidor built, has a web app plus an iOS app on the App Store where customers track points and redeem rewards. Omhar builds mobile apps with React Native. Visit Noxa Loyalty.

Omhar Regidor builds with Next.js, React, TypeScript and Tailwind CSS on the front end, and Node.js, Express, Supabase, PostgreSQL, MySQL and MongoDB on the back end. He uses React Native for mobile, n8n with OpenAI for automation, and Docker with GitHub Actions for delivery. See all 33 tools.

What is n8n?

n8n is a workflow automation tool that connects apps like Gmail, Shopify and Slack so routine tasks run on their own. Each workflow is a chain of steps, called nodes, that starts from a trigger such as a new email, a chat message or a daily schedule.

What is an AI agent?

An AI agent is an AI model given a specific job and the tools or information it needs to act on it, not just chat. In Omhar Regidor’s SOP Assistant, the agent reads a staff question and answers it from the company’s written procedures.
